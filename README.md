# Contoso University

Educational web application developed using ASP.NET Core MVC and Entity Framework Core.

## Live Demo

http://contoso-revive.runasp.net

## Technologies

* ASP.NET Core MVC
* Entity Framework Core
* SQL Server
* Razor Views
* Bootstrap

## Features

* Student management
* Course management
* Enrollment management
* Department management
* Instructor management
* Database integration with SQL Server
* CRUD operations
* Entity Framework Core migrations

## Database

The application uses SQL Server and Entity Framework Core for data access and database management.
